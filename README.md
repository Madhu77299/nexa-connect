## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18.0 or later)
- npm / yarn / pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Madhu77299/nexa-connect.git
cd nexa-connect

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

The app will be accessible at `http://localhost:5173`.

### Production Build & Deployment

```bash
# Create optimized production build
npm run build

# Deploy to Surge.sh
powershell -Command "Copy-Item dist/index.html dist/200.html -Force"
npx surge ./dist --domain pmk-nexa-solutions.surge.sh
```
